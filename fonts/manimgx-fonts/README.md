# manimgx-fonts

The fonts [ManimGX](https://manimgx.academa.ai) sets text in, besides Typst's own: Noto Sans
(upright and italic), Noto Emoji, Noto Sans Symbols, and Noto Sans for the scripts Latin faces
lack (Arabic, Armenian, Bengali, Devanagari, Ethiopic, Georgian, Gujarati, Gurmukhi, Hebrew,
Kannada, Khmer, Lao, Malayalam, Myanmar, Oriya, Sinhala, Tamil, Telugu and Thai), as Noto
publishes them. ManimGX requires it, so that text is set the same on every machine; Chinese,
Japanese and Korean are in [manimgx-fonts-cjk](https://pypi.org/project/manimgx-fonts-cjk/).
