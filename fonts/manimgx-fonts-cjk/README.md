# manimgx-fonts-cjk

Noto Sans CJK, as Noto publishes it: the font [ManimGX](https://manimgx.academa.ai) sets Chinese,
Japanese and Korean text in. ManimGX requires it everywhere but in the browser, where 33 MB is
too much for a page to download; the rest of its fonts are in
[manimgx-fonts](https://pypi.org/project/manimgx-fonts/).
